# Boost Frontend - Модуль достижений

Фронтенд-часть модуля Boost для платформы Сигма. Реализует интерфейс управления шаблонами достижений (ачивок), их создания, просмотра статусов и ручной выдачи

## 🧱 Стек технологий

- **React 19** - ядро приложения
- **TypeScript** - строгая типизация
- **Chakra UI v3** - компоненты и дизайн-система
- **Vite** - сборка и разработка
- **ESLint + TypeScript ESLint** - контроль качества кода

На данный момент проект находится в стадии **MVP**. Весь функционал работает на моковых данных (демо-режиме), что позволяет тестировать UI и логику без подключенного бэкенда

## 🔌 Интеграция с бэкендом

В коде предусмотрены места для подключения реального API.
Активация реального API выдачи ачивки
Откройте файл src/api/boostApi.ts. В функции issueAchievement сейчас используется мок-логика

## 🎯 Функционал

- **Создание ачивки**: форма с валидацией, выбор статуса и цвета иконки
- **Выдача ачивки**: выбор сотрудника из списка, подтверждение действия, отображение уведомления
- **Статусы**: поддержка статусов `active`, `draft`, `archived` с визуальным отображением.
- **Демо-режим**: все операции работают на моковых данных без бэкенда

## 🚀 Как запустить

### Локальная разработка

1.  Установите зависимости:
    ```bash
    npm ci
    ```
2.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```
3.  Откройте в браузере: `http://localhost:5173`.
